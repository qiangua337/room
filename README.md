# 回到家 · 3D 漫游

根据参考照片重建的 Three.js 场景，包括双侧高架床、书桌、衣柜、洗漱区、浴室与阳台。最终房屋及家具整体等比例放大为初版的 2 倍，第一人称视点高度为 1.65 米。空间为照片推测的美化还原。

## 操作

- WASD / 方向键：移动；Shift：快走。
- 鼠标拖动：环顾；点击“进入漫游”可锁定鼠标；Esc：释放鼠标。
- E：靠近门时开关门；C：开关窗帘。
- F：切换小狗跟随 / 自由活动。
- 俯瞰全屋：拖动旋转，滚轮缩放。
- 平面图下方按钮：快速前往对应区域。
- 手机：左下摇杆移动，拖动场景环顾，点击互动按钮开关门。

## 修改源码

解压“回到家-ThreeJS源码.zip”，使用 Node.js 20.19+ 或 22.12+。

```text
npm install
npm run dev
```

打开终端显示的本地网址。生成可发布版本使用 `npm run build`，输出在 dist 文件夹。

- src/world.js：房屋结构、材质、门和碰撞；HOME_SCALE 控制整体比例。
- src/furniture.js：床铺、楼梯、桌椅和衣柜。
- src/dog.js：小狗造型及骨架动画。
- src/main.js：第一人称操作、宠物寻路、界面互动。
- src/style.css：界面外观及手机适配。

未包含用户原始照片。模型在浏览器内生成，无需下载外部 3D 模型。
